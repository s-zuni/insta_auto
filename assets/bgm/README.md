# BGM 폴더

Pixabay Music 등 **상업적 이용이 가능한 무료 음원**을 mp3로 내려받아 아래 폴더에 넣으세요.

| 폴더 | 쓰이는 시리즈 | 추천 분위기 |
|---|---|---|
| `bright/` | MBTI | 경쾌한 lo-fi, 팝 인스트루멘탈 |
| `calm/` | DAILY(오행) | 잔잔한 앰비언트, 피아노 |
| `mystic/` | SAJU, SHINJEOM, JAMIDOSU, TAROT | 신비로운 앰비언트, 시네마틱, 동양풍 |
| `default/` | 위 폴더가 비었을 때 대체 | 무난한 배경음 |

- 가사 없는 인스트루멘탈, 길이 60초 이상 권장 (영상보다 짧으면 반복 재생)
- 영상 제목으로 트랙이 고정 선택되며, 폴더에 파일이 여러 개면 영상마다 다른 곡이 쓰입니다.
- 음원이 하나도 없으면 BGM 없이 영상이 만들어집니다.
- 볼륨은 `.env`의 `BGM_VOLUME`(기본 0.18)로 조절하며, 나레이션이 나올 때는 자동으로 더 낮아집니다.
